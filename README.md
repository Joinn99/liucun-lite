# 留存 · 轻量工程

在浏览器中组合 Bilibili 页面信息、评论与分P弹幕，下载工程文件或静态页面。

本仓库仅包含静态部署文件和轻量采集扩展，不包含用户采集数据。

## 使用

从页面下载采集扩展并解压，在已登录 B站的 Edge / Chrome 配置中加载。采集完成后下载 JSON，再导入在线编辑器。

工程只保存在当前页面内存中，正式保存请下载工程文件。图片可保留原链接，或在最终导出时由浏览器直接下载；网站服务器不接收工程内容。

无需本地服务，不包含视频播放器。弹幕 XML / ASS 可交给自己的本地播放器使用。

第三方许可见 THIRD_PARTY_LICENSES.txt。
